# Editora Inovação / Inovação Media Brasil

Legacy projects from [Editora Inovação](https://editorainovacao.com.br), a Brazilian publishing and media company.

## 📦 About this organization

This organization hosts the source code of systems, websites, and tools developed for **Editora Inovação / Inovação Media Brasil**. The repositories are preserved here for historical reference and legacy maintenance.

> [!IMPORTANT]
> **Managed by [@guibranco](https://github.com/guibranco)**
>
> I worked at Editora Inovação as an employee from **2011 to 2018** and as a freelancer from **2018 to 2021**.
> Since the company had no other developers or engineers, I retain custody of this code to preserve the projects and their history.

## 🗄️ Project status

Most repositories in this organization are **legacy projects** and are no longer under active development. They remain available for reference and receive occasional maintenance only.
